# skills

> Нужно делать так, как нужно, а так, как не нужно, делать не нужно.
>
> — *Народная мудрость*

Скиллы для Claude Code, собранные из лучших книг по своей теме. Я делал их для себя, а храню на GitHub, чтобы не потерять, и заодно делюсь ими со всеми.

Этот репозиторий — маркетплейс: все скиллы лежат в папке [plugins](plugins), и устанавливают их отсюда же.

## С чего начать: clean-writing

Если ставить только один скилл, то [clean-writing](plugins/clean-writing). С ним агент пишет понятно и по-человечески: начинает с ответа, заменяет канцелярит глаголами и подкрепляет оценки фактами. Правила работают в каждом ответе в чате и во всех текстах, которые агент пишет людям: задачах, PR, README, документации, письмах.

Без скилла агент на вопрос «почему падает импорт» отвечает так:

> Отличный вопрос! Давайте разберёмся. Я изучил модуль и посмотрел логи. В рамках анализа было выявлено, что причиной ошибки является отсутствие проверки входных данных.

Со скиллом ответ начинается с сути:

> Импорт падает на пустом файле: парсер не проверяет его длину.

Правила сведены из 11 книг о ясном письме: от «Слова живого и мёртвого» Норы Галь и «Пиши, сокращай» Максима Ильяхова до «The Sense of Style» Стивена Пинкера и «Принципа пирамиды» Барбары Минто. Если авторы расходились, в свод попал один вариант.

## Свой скилл по книгам: skillstrap

[skillstrap](plugins/skillstrap) собирает плагин со скиллом по любой теме, например по Kubernetes, код-ревью или SQL. Он работает так:

1. Уточняет границы темы, что агент должен делать лучше и как назвать плагин.
2. Предлагает 6–10 книг, каждая из которых раскрывает свою сторону темы, и сверяет издания с последними. Список вы утверждаете сами.
3. Конвертирует в Markdown файлы книг, которые вы положили в папку.
4. Конспектирует каждую книгу отдельным субагентом: выписывает правила с примерами.
5. Сводит конспекты в один свод правил и собирает готовый плагин для Claude Code.

## Установка

Подключите маркетплейс и установите нужный скилл:

```
/plugin marketplace add maximsakhno/skills
/plugin install clean-writing@maximsakhno
```

В Claude Code 2.1.275 и новее хватит одной команды:

```
/plugin install clean-writing --marketplace maximsakhno/skills
```
