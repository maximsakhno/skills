# clean-writing

Плагин для Claude Code, который учит агента писать по-русски ясно: начинать с ответа, писать глаголами вместо канцелярита и подкреплять оценки фактами. Правила действуют для каждого ответа в чате и для текстов, которые агент пишет людям: задач, MR, README, документации, писем.

Например, на вопрос «почему падает импорт» агент без правил часто отвечает так:

> Отличный вопрос! Давайте разберёмся. Я изучил модуль и посмотрел логи. В рамках анализа было выявлено, что причиной ошибки является отсутствие проверки входных данных.

С правилами ответ начинается с сути:

> Импорт падает на пустом файле: парсер не проверяет его длину.

## Установка

```
/plugin marketplace add maximsakhno/skills
/plugin install clean-writing@maximsakhno
```

С Claude Code 2.1.275 и новее хватит одной команды:

```
/plugin install clean-writing --marketplace maximsakhno/skills
```

Больше ничего настраивать не нужно: правила подключатся со следующей сессии.

## Как правила попадают к агенту

Правила хранятся в двух версиях, потому что Claude Code обрезает то, что хук добавляет в контекст, до 10 000 символов, а полный свод занимает около 27 000.

- **Сжатая версия действует всегда.** Хук `SessionStart` добавляет её в контекст при старте и возобновлении сессии, после `/clear` и после сжатия контекста. В ней все правила, записанные коротко, и около 30 примеров. Она занимает около 8 400 символов контекста.
- **Полный свод агент загружает сам.** Это скилл `clean-writing:clean-writing` с подробными правилами и примерами «плохо → хорошо». Агент загружает его перед документом, длинным текстом или правкой чужого текста. Вызвать вручную: `/clean-writing:clean-writing`.

Сжатая версия гарантирует, что правила соблюдаются в каждом ответе. Полный свод нужен для точности: по примерам агенту видно, где проходит граница правила. Но загрузит ли он его, агент решает сам.

## Ограничения

- **Правила написаны для русского языка.** В текстах на английском действуют все, кроме правил о канцелярите и кальках.
- **Правила — инструкция, а не фильтр.** Агент следует им, но проверки готового текста нет, и отступления возможны.

## Как изменить правила

Правило меняют в двух файлах:

- `skills/clean-writing/SKILL.md` — полный свод;
- `skills/clean-writing/core.md` — сжатая версия для хука.

После правки проверьте, что вывод хука короче 10 000 символов, иначе Claude Code его обрежет:

```
CLAUDE_PLUGIN_ROOT=. bash scripts/inject-rules.sh | wc -m
```

Проверить плагин и запустить его без маркетплейса:

```
claude plugin validate .
claude --plugin-dir .
```

## Откуда правила

Правила сведены из 11 книг о письме. Где авторы расходились, в своде выбран один вариант.

- Барбара Минто, «Принцип пирамиды Минто»
- Максим Ильяхов, «Ясно, понятно»
- Максим Ильяхов, Людмила Сарычева, «Пиши, сокращай»
- Нора Галь, «Слово живое и мёртвое»
- Steven Pinker, «The Sense of Style»
- Joseph M. Williams, Joseph Bizup, «Style: Lessons in Clarity and Grace»
- Joshua Schimel, «Writing Science»
- Chip Heath, Dan Heath, «Made to Stick»
- Steve Krug, «Don't Make Me Think, Revisited»
- Jared Bhatti и соавторы, «Docs for Developers»
- Anne Lamott, «Bird by Bird»
